# Task App 📝

A simple and clean task management application built using **Flutter** and **Hive** for local data storage.  
This project was created for training and to practice:

- Working with Hive database
- Creating, reading, updating, and deleting data (CRUD)
- Passing and managing data between screens
- Using custom UI components
- Handling TextEditingControllers properly

---

## 📱 Features

✔ Add a new task (Title + Content + Created Date)  
✔ Edit existing tasks  
✔ Delete a specific task  
✔ Delete all tasks from AppBar  
✔ Local offline storage using **Hive**  
✔ Smooth and minimal user interface  
✔ Data persists after restarting the app  

---

## 🧰 Tech Stack

| Technology | Usage |
|----------|-------|
| Flutter | UI and App structure |
| Dart | Business logic & data handling |
| Hive | Local NoSQL database to store tasks |
| TextEditingController | Input control for editing tasks |

## 🚀 How It Works

1️⃣ Add a task using the floating action button  
2️⃣ The task is saved inside **Hive box: "tasks"**  
3️⃣ All tasks appear in a ListView  
4️⃣ Edit or delete any task directly from the list
